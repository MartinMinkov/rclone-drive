rclone-drive privacy policy

rclone-drive is a personal tool used only by its owner, Martin Minkov. This policy describes how it handles Google user data.

Data accessed

With the owner's consent, rclone-drive accesses the files and file metadata in the owner's Google Drive.

How the data is used

The data is used only to list, download, upload and sync files at the owner's request. It is not used for advertising, analytics, profiling or training models.

Storage

Files and the OAuth token are stored only on computers the owner controls. No server operated for this tool receives them.

Sharing

Google user data is never sold, shared with or transferred to third parties. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.
